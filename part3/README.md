## API Endpoints

- `GET /api/persons` — Get all phonebook entries
- `GET /api/persons/:id` — Get a single entry by id
- `POST /api/persons` — Add a new entry
- `DELETE /api/persons/:id` — Delete an entry
- `GET /info` — Show phonebook info and request time
